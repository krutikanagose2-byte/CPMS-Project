# Placement Homepage (React + Vite)

Professional, responsive React single-page layout that reproduces the placement homepage UI.

Features
- Vite + React (fast dev server)
- ESLint + Prettier for consistent code style
- Simple responsive layout and components

Quick start

```bash
cd D:/CPMS-Proj
npm install
npm run dev
```

Useful scripts
- `npm run dev` — start development server
- `npm run build` — build for production (output in `dist/`)
- `npm run preview` — locally preview production build
- `npm run lint` — run ESLint on `src/`
- `npm run format` — run Prettier across source files

Contributing
- Edit components under `src/components`
- Run `npm run lint` and `npm run format` before committing
